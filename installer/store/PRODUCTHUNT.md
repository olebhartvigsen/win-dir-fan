## First comment (maker's story)

Hi Product Hunt,

I built FanFolder because I kept losing files I had open twenty minutes ago. The sheet was in one place. The PDF was in another. Each time I had to open Explorer, click Recent, and squint at a list. By then I had lost my train of thought.

FanFolder puts one icon on the taskbar. Click it and your recent files fan out in an arc. Click one to open it. Right click for the same Windows menu you know, so copy, rename and delete work as you expect. Drag a file out of the fan into an email or a chat. Drag a file from Explorer into the fan to move it.

It does not have to be recent files. Point it at Downloads. Point it at the folder for the job that is eating your week. Sort by date or by name. Cap how many items show. Add a regex if you only want PDFs.

A few things I care about, and you might too.

It is native Win32 and C++. The app is about 161 KB. There is no .NET runtime to install. It starts at once and sits near zero CPU when you leave it alone.

It is free for home and work use, forever. No account. No trial clock. No upsell screen. There is a tip jar if you want one, and you can ignore it.

It sends one event on first run so I can tell if anyone uses this. No file names. No paths. No account data. One registry value turns it off, and the readme shows you which one.

It ships in 29 languages. It runs on Windows 10 and 11, x64.

Get it from the Microsoft Store, with `winget install FanFolder`, or as a direct download from the site.

I work on this alone, so I read all of it. If the fan is too slow, if you want a new sort order, if it breaks on your box, tell me here and I will fix it.
