## FanFolder 1.3.0

New version bump for OleBhartvigsen.FanFolder. Manifests were generated by `wingetcreate update` from the published v1.3.0 MSIs (SHA256 and ProductCode computed from the shipped installers).

### Note for the validator

FanFolder lives in the taskbar. To open the fan, single-click its taskbar icon — there's no main window that comes up on its own.

One thing you'll likely hit in a clean sandbox: the default source is the Windows recent-documents list, and on a fresh VM that list is empty. When it's empty the fan shows a small "This folder is empty" item. That's the app working correctly, not stalling — it was fixed back in 1.2.2 so the fan never renders as a blank window with a spinner.

What's new in 1.3.0:
- "Open FanFolder homepage" item on the tray right-click menu (opens the project page in the default browser).
- Anonymous first-run install reporting via Aptabase (EU-hosted, privacy-friendly; opt-out via `TelemetryEnabled=0` in `HKCU\SOFTWARE\FanFolder`; full details in PRIVACY.md). No personal data, file paths, or usage details are sent.

Everything installs per-user (`Scope: user`), so no elevation is needed or requested.

### Installer details
- Per-user MSI, x64 and ARM64
- Silent install verified: `/quiet /norestart`
- SHA256 and ProductCode taken from the shipped v1.3.0 MSIs
